# MamaMate AI – For Women's Health Assistant

**What is MamaMate AI?**
MamaMate AI is an intelligent backend system designed to assist women during pregnancy and other important life stages. It uses artificial intelligence to provide personalized, reliable, and safe information related to:
Gynecology, Mental health, Sex education, Motherhood
This system is part of the MamaMate platform and serves as the AI brain behind the mobile app.

**What Makes It Special?**
MamaMate AI is built using an agentic architecture. This means the AI is capable of making decisions, selecting tools, and retrieving the right information for each user query — just like a smart assistant would.

Unlike simple chatbots, this system can:

Think through user questions
Search through stored knowledge
Decide the best tool to use
Respond with accurate, personalized answers

**Technologies Used**
This backend combines powerful tools from the AI ecosystem:

**LangChain** – To build the AI workflow and agent logic
**FastAPI** – For creating RESTful API endpoints
**ChromaDB** – To store and retrieve knowledge in vector format (used in RAG)
**MongoDB** – To maintain long-term memory of conversations
**OpenAI Tool Calling** – To enable the AI agent to choose actions based on user intent

**Purpose of This Repository**
This repository contains all backend logic required for:

Setting up the AI chat system
Connecting to vector and memory databases
Handling incoming chat requests via API
Managing document ingestion for RAG (Retrieval-Augmented Generation)
Customizing the behavior of the AI agent
